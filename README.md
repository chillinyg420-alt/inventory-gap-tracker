# 재고조사 차이 추적기 (v10)

재고조사 후 ARS 엑셀 3개(+선택 2개)를 올리면 **차이내역을 원인별로 분류**하고 결재용 **「인수인계 재고조사 확인서」(.xlsx)** 를 자동 생성하는 웹도구.
서버 없이 브라우저에서만 처리 (파일 외부 전송 없음). GitHub Pages 단일 HTML.

## 배포
1. GitHub 저장소(예: `InventoryGap`)에 `index.html`, `robots.txt` 업로드
2. Settings → Pages → Branch `main` / root → 저장
3. 수정 배포 시 캐시 회피용으로 `index_v2.html` 식 버전 파일명 사용
- 검색 차단: `<meta name="robots" content="noindex, nofollow">` + `robots.txt Disallow: /`

## 입력 파일 (ARS)
| 메뉴 | 조회 조건 | 용도 |
|---|---|---|
| 재고실사 본사전송 | 재고조사일자 = 이번 조사일 | 실사재고(I열) |
| 스타일별 입출고실적조회 | 조회기간 = 조사 다음날, 사이즈별 | 장부재고(H열) |
| 거래내역 상세조회 | **직전 조사일 ~ 이번 조사 전날** (조사 당일 스캔 후 판매분은 매장 수기 조정) | 원인 추적 |
| 재고실사 내역조회 (선택) | 재고조사일 = 직전 조사일 | 직전 조사 로스/과다 대조 (없으면 이 판정만 생략) |
| **재고실사 내역조회 — 최종** | 재고조사일 = 이번 조사일 (조사 완료 후) | 최종 확인서: 장부(H)·실사(I)·추가등록(J)을 ARS 확정 수량 그대로 사용. 이 파일 하나로도 확인서 완성 |
| 재고실사 차이분등록 (선택) | 재고조사일자 = 이번 조사일 | 본사전송 전 수기 보정(스캔누락 +, 과스캔 − 등) → 확인서 **J열 추가등록수량**에 기입 |

파일 종류는 1행 제목으로 자동 인식. 재고실사 내역조회는 날짜로 구분: 이번 조사일(본사전송 조사일, 또는 거래내역 끝+1일) 이후 = 최종, 이전 = 직전 조사. ARS xlsx 범위 잘림 문제는 `fixTruncatedRange`로 보정. `합계` 행 제외.

## 처리 로직
- 최종 모드(내역조회-최종 있음): 본사전송·입출고실적 불필요. 거래내역·직전 내역조회·차이분등록(비고 문구용)을 같이 올리면 사유가 더 채워짐. 입출고실적을 같이 올리면 부족 금액 표시
- 매칭 키: 스타일 + 컬러 + 사이즈 (실사 스캔 중복행은 합산)
- 차이분등록이 있으면: I열 = 스캔 수량, **J열 = 차이분등록 수량**, K열 = I+J−H
- 차이분등록으로 차이가 0이 된 품목은 확인서에서 제외. 차이가 남은 품목만 J열에 등록 수량 기입
- 차이 = 실사 − 장부, 0인 품목 제외
- 보정 후에도 남은 차이: 사유 앞에 `차이분등록 ±n(비고) 반영 후 잔여 ±n`
- 스캔=장부였는데 차이분등록으로 생긴 차이: 매장 등록 사유를 그대로 사유로 사용 (`수기 등록`, 할 일 없음)
- 경고: 차이분등록 조사일자 ≠ 본사전송 조사일
- 판정 순서
  1. **사이즈/컬러 돌아감**: 동일 스타일 내 +/− 상쇄 (컬러·사이즈가 같은 짝 우선, 둘 다 달라도 같은 상품이면 상쇄) → 2차로 동일 브랜드+상품명(시즌코드 다른 스타일) 상쇄. 잔여 수량 표시
  2. **이전 재고조사 로스/과다 반영**: 직전 조사 차이(−)인 품목이 금회 (+) 또는 그 반대
  3. **전표 의심**: 장부 마이너스 / 점간이동 출고·입고 / 매장반품 / 기타출고 / 최근 14일 물류입고 / 판매취소
  4. **거래내역 추정**: 과다 — 판매취소 이력(판매·취소 수량 대비 회수 착오) / 판매 이력(판매 후 실물 잔류, 같은 날 타옵션 판매 병기) / 마지막 거래가 입고(오출고). 부족 — 마지막 거래가 입고(미도착·검수 누락)
  5. 직전 조사 때 같은 스타일 다른 옵션에 차이 → "옵션 혼동 가능"
  6. 그 외: 과다 → 과재고(사유작성 必), 부족 → 분실, **사유 공란** (전산 근거 없는 건은 추정하지 않음)
- 원칙: 비고는 항상 채움 / 사유는 근거(상쇄 짝, 전표, 거래내역, 직전 조사, 실사 0)가 있을 때만 작성
- 화면의 '할 일' 열(재스캔, 전표 대조 등)은 도구 화면 전용, 확인서에는 미기재
- 재스캔 필요: (a) 스타일 전체 실사 0 & 장부 2개 이상, 또는 (b) 같은 스타일 2개 이상 옵션이 실사 0 — 스타일 통째·여러 사이즈 스캔 누락. 해당 품목은 돌아감 매칭에서 제외

- 경고: 매장 불일치 / 거래내역 끝이 조사 전날이 아님 / 거래내역 시작 ≠ 직전 조사일

## 출력 (확인서 양식 그대로)
- `차이내역 원본데이터` / `차이내역 사유 작성서` 시트, 비고 드랍다운 6종, K열 = `I+J−H` 수식, J(추가등록) = 차이분등록 수량 (없으면 공란)
- 이전 재고조사 반영 건이 있으면 `이전재고조사 첨부` 시트 자동 추가

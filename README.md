# 재고조사 차이 추적기 (v4)

재고조사 후 ERP 엑셀 3개(+선택 1개)를 올리면 **차이내역을 원인별로 분류**하고 결재용 **「인수인계 재고조사 확인서」(.xlsx)** 를 자동 생성하는 웹도구.
서버 없이 브라우저에서만 처리 (파일 외부 전송 없음). GitHub Pages 단일 HTML.

## 배포
1. GitHub 저장소(예: `InventoryGap`)에 `index.html`, `robots.txt` 업로드
2. Settings → Pages → Branch `main` / root → 저장
3. 수정 배포 시 캐시 회피용으로 `index_v2.html` 식 버전 파일명 사용
- 검색 차단: `<meta name="robots" content="noindex, nofollow">` + `robots.txt Disallow: /`

## 입력 파일 (ERP)
| 메뉴 | 조회 조건 | 용도 |
|---|---|---|
| 재고실사 본사전송 | 재고조사일자 = 이번 조사일 | 실사재고(I열) |
| 스타일별 입출고실적조회 | 조회기간 = 조사 다음날, 사이즈별 | 장부재고(H열) |
| 거래내역 상세조회 | **직전 조사일 ~ 이번 조사 전날** (조사 당일 스캔 후 판매분은 매장 수기 조정) | 원인 추적 |
| 재고실사 내역조회 (선택) | 재고조사일 = 직전 조사일 | 직전 조사 로스/과다 대조 (없으면 이 판정만 생략) |

파일 종류는 1행 제목으로 자동 인식. ERP xlsx 범위 잘림 문제는 `fixTruncatedRange`로 보정. `합계` 행 제외.

## 처리 로직
- 매칭 키: 스타일 + 컬러 + 사이즈 (실사 스캔 중복행은 합산)
- 차이 = 실사 − 장부, 0인 품목 제외
- 판정 순서
  1. **사이즈/컬러 돌아감**: 동일 스타일 내 +/− 상쇄 (컬러 또는 사이즈 중 하나는 같아야 함) → 2차로 동일 브랜드+상품명(시즌코드 다른 스타일) 상쇄. 잔여 수량 표시
  2. **이전 재고조사 로스/과다 반영**: 직전 조사 차이(−)인 품목이 금회 (+) 또는 그 반대
  3. **전표 의심**: 장부 마이너스 / 점간이동 출고·입고 / 매장반품 / 기타출고 / 최근 14일 물류입고 / 판매취소
  4. **거래내역 추정**: 과다 — 판매취소 이력(판매·취소 수량 대비 회수 착오) / 판매 이력(판매 후 실물 잔류, 같은 날 타옵션 판매 병기) / 마지막 거래가 입고(오출고). 부족 — 마지막 거래가 입고(미도착·검수 누락)
  5. 직전 조사 때 같은 스타일 다른 옵션에 차이 → "옵션 혼동 가능"
  6. 그 외: 과다 → 과재고(사유작성 必), 부족 → 분실, **사유 공란** (전산 근거 없는 건은 추정하지 않음)
- 원칙: 비고는 항상 채움 / 사유는 근거(상쇄 짝, 전표, 거래내역, 직전 조사, 실사 0)가 있을 때만 작성
- 화면의 '할 일' 열(재스캔, 전표 대조 등)은 도구 화면 전용, 확인서에는 미기재
- 재스캔 필요: 실사 0 & 장부 3 이상, 또는 차이 3족 이상 (스캔 누락 가능성)

- 경고: 매장 불일치 / 거래내역 끝이 조사 전날이 아님 / 거래내역 시작 ≠ 직전 조사일

## 출력 (확인서 양식 그대로)
- `차이내역 원본데이터` / `차이내역 사유 작성서` 시트, 비고 드랍다운 6종, K열 = `I+J−H` 수식, J(추가등록) 공란
- 이전 재고조사 반영 건이 있으면 `이전재고조사 첨부` 시트 자동 추가

## 소스 구조
- `logic.js` (파싱·분석·엑셀 생성, 브라우저/Node 공용) → `index.html`에 인라인
- 라이브러리: SheetJS 0.18.5(읽기), ExcelJS 4.4.0(서식·드랍다운 쓰기) — cdnjs
- 검증: ST 구미인동점 2026-10-26 실데이터 (장부 14,382 / 실사 14,381 / 차이 75줄)

# 재고조사 차이 추적기 (v11)

ARS 엑셀을 올리면 차이 목록을 정리해 **양식 그대로** 내려받는 웹도구. 브라우저 안에서만 처리(파일 외부 전송 없음). GitHub Pages 단일 HTML.
배포 주소: https://chillinyg420-alt.github.io/inventory-gap-tracker/

## 배포
1. 저장소 `inventory-gap-tracker`에 `index.html`, `robots.txt` 업로드 → Settings → Pages → `main` / root
2. 검색 차단: `<meta name="robots" content="noindex, nofollow">` + `robots.txt Disallow: /`

## 두 가지 작업 (화면 상단 탭으로 구분)
| | ① 본사전송 전 차이 추적 | ② 최종 확인서 출력 |
|---|---|---|
| 언제 | 스캔 후 **본사전송 전** | 재고조사 **완료 후**(본사전송·차이분등록 끝) |
| 목적 | 스캔 누락 상품 찾기 | 결재 확인서 '차이내역 사유 작성서'에 붙여넣을 시트 |
| 필요한 파일 | 재고실사 본사전송 + 스타일별 입출고실적조회(사이즈별) | 재고실사 내역조회 (재고조사일 = 이번 조사일) |
| 담는 품목 | 실사 ≠ 장부 | 현재차이수량 ≠ 0 |
| 다운로드 양식 | `본사전송 전 재고차이 추적` A~K: NO·브랜드·상품·스타일·컬러·사이즈·장부·실사·현재차이(=H−G)·**등록일자·상품위치**(본사전송 파일) | `재고실사 내역조회 붙여넣기` A~K: NO·브랜드·상품·스타일·자사스타일·컬러·사이즈·장부·실사·추가등록·현재차이(=I+J−H), 제목·안내문·매장명·조사일 |
| 파일명 | 본사전송전재고차이추적_매장_조사일.xlsx | 재고실사내역조회붙여넣기_매장_조사일.xlsx |

- 공통: **오름차순** 정렬(브랜드 → 스타일 → 컬러 → 사이즈), 데이터 뒤 빈 줄 10개 + 합계(SUM) 행, 숫자 서식 `#,##0_ ;[Red]-#,##0`
- 다른 탭용 파일을 올리면 "이 파일은 ②용입니다" 안내 후 무시. 거래내역·차이분등록 파일은 사용하지 않음
- ① 화면: 부족/과다/재스캔 필요 필터. 재스캔 필요 = 스타일 전체 실사 0(장부 2개 이상) 또는 같은 스타일 2개 이상 옵션 실사 0 (화면 표시만, 파일에는 미기재)
- ② 화면: 현재차이 합계를 ARS 내역조회 합계와 대조해 일치 여부 표시
- 파일 종류는 1행 제목으로 자동 인식. ARS xlsx 범위 잘림은 `fixTruncatedRange`로 보정, `합계` 행 제외

## 소스
- `logic.js` (파싱·집계·엑셀 생성, 브라우저/Node 공용) → `index.html`에 인라인. SheetJS 0.18.5(읽기), ExcelJS 4.4.0(쓰기) — cdnjs
- 검증: ① ST 구미인동점 10/26 → 75줄(부족 −64, 과다 +63, 재스캔 필요 3) / ② ST 구미원평점 10/27 → 21줄, 첨부 양식과 셀 단위 일치, 현재차이 −16 = ARS 합계
- 이전 버전(v10: 거래내역 기반 비고·사유 자동 작성)은 v11에서 제외 — 사용자 결정(양식 A~K 그대로)
